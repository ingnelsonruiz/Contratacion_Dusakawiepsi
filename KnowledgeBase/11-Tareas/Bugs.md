# Bugs

## Estado actual

> [!info]
> No se identificaron **bugs funcionales confirmados** en el código actual durante este análisis — el alcance de Fase 0 es pequeño (autenticación + placeholder de dashboard) y su lógica es simple y directa. Lo que sí existen son **riesgos de diseño y deuda técnica**, documentados en [[Problemas Comunes]] (no son bugs en el sentido de "comportamiento incorrecto observado", sino decisiones que requieren endurecerse antes de producción).

## Cómo reportar un bug nuevo aquí

Al encontrar un bug real durante el desarrollo de las fases futuras, documentarlo con esta plantilla:

```markdown
## [Título corto del bug]

- **Módulo/archivo**: 
- **Síntoma observado**: 
- **Pasos para reproducir**: 
- **Comportamiento esperado**: 
- **Estado**: abierto / en progreso / resuelto
- **Enlace a la solución** (si existe): [[Soluciones#...]]
```
